# 🤖 NeuraChat AI

NeuraChat AI is an intelligent multilingual AI chatbot developed as a college AI project.

It helps users with education, coding, general knowledge and everyday questions through a friendly chat interface.

## ✨ Features

- 🤖 AI-powered conversations
- 🌐 Multilingual support
- 💬 Real-time chat
- 🎤 Voice assistant support
- 📚 Helpful for education and coding
- 😊 Friendly and simple responses

## 🛠️ Technologies Used

- Python
- Flask
- Google Gemini API
- HTML
- CSS
- JavaScript

🚀 How It Works
User opens NeuraChat AI.
User clicks Start Chat.
The chat interface opens.
User sends a message.
Flask sends the request to the Google Gemini API.
Gemini generates a response.
The response is displayed in the chat interface.
